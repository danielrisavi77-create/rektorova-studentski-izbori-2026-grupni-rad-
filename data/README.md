# Zaključani analitički podatci

Ova mapa sadrži podatkovne ulaze statusa `FINAL_DATA_LOCK`, lock cycle `5`.

- `panel_wide.csv` — kanonski široki panel, 178 redaka.
- `panel_long.csv` — kanonski dugi prikaz istog panela.
- `sources.csv` — strukturirani registar središnjih izvora.

Nedostupne ili službeno neprovjerljive vrijednosti ostaju nedostajuće. **Nema imputacije radi popunjavanja dokumentacijskih praznina.** Svaka stvarna promjena zaključanih podataka zahtijeva novi lock cycle i novi research release.

Kanonski SHA-256 otisci zaključanih datoteka navedeni su u `docs/REPRODUCIBILITY_BLOCKERS.md` dok se ne dovrši novi repo-root `MANIFEST.json`.
